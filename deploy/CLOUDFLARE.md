# پادو و Cloudflare: چه چیزی شدنی است

خلاصه: **کل برنامه روی Cloudflare Workers یا Pages اجرا نمی‌شود، اما Cloudflare جلوی VPS به‌خوبی کار می‌کند.** پیشنهاد: برنامه روی VPS (پوشه `vps/`) و Cloudflare به عنوان DNS، CDN و سپر حمله.

## چرا API و worker روی Workers اجرا نمی‌شوند

| بخش | نیاز | Workers |
|---|---|---|
| worker (صف BullMQ) | پروسه همیشه روشن که به Redis وصل می‌ماند (یادآوری نوبت، پیامک، هوش مصنوعی، همگام‌سازی اینستاگرام) | پروسه همیشه روشن ندارد؛ هر درخواست جدا اجرا می‌شود |
| پردازش عکس | `sharp` (ماژول native) | ماژول native اجرا نمی‌شود |
| فایل‌های آپلودی | دیسک محلی | دیسک ندارد؛ باید به R2 یا فضای ابری منتقل شود |
| API (Fastify) | سرور Node.js | باید برای مدل درخواست به درخواست Workers بازنویسی شود |

انتقال کامل یعنی بازنویسی بخش بزرگی از بک‌اند، صف‌ها و ذخیره فایل؛ برای این مرحله ارزشش را ندارد.

## بخش وب (Next.js) روی Workers: شدنی ولی با شرط

آداپتور رسمی OpenNext برای Cloudflare (`@opennextjs/cloudflare`، نسخه 1.20.10) نسخه `next` را `>=16.3.8` می‌خواهد و پروژه الان روی 16.3.6 است؛ پس اول ارتقای Next لازم است. بعد از آن فقط صفحه‌ها روی Workers می‌روند و API همچنان باید روی VPS بماند (آدرس API در `API_INTERNAL_URL` موقع build). سود این کار در عمل کم است چون هر صفحه پنل و فروشگاه داده را از همان VPS می‌گیرد.

## نکته مهم برای ایران

- بسیاری از درگاه‌های بانکی و سرویس‌های پیامک ایرانی IP سرور را ثبت می‌کنند و ممکن است IP ایران بخواهند؛ درخواست به آن‌ها از VPS ارسال می‌شود، نه از Cloudflare، پس این محدودیت با راه پیشنهادی مشکلی ندارد. شرایط دقیق را از بانک بپرسید.
- اگر سرور در ایران است و بیشتر کاربران هم در ایران، تست کنید که عبور از Cloudflare سرعت را بهتر می‌کند یا بدتر؛ گاهی اتصال مستقیم به سرور ایران سریع‌تر است.

## راه‌اندازی Cloudflare جلوی VPS

۱. دامنه را به Cloudflare اضافه کنید و Nameserverها را در ثبت‌کننده دامنه عوض کنید.
۲. رکورد A دامنه را به IP سرور بدهید، **اول با ابر خاکستری (DNS only)**.
۳. روی سرور `deploy/vps/deploy.sh` را اجرا کنید تا Caddy گواهی HTTPS را بگیرد.
۴. بعد ابر را نارنجی کنید (Proxied) و در SSL/TLS حالت **Full (strict)** را بگذارید.
۵. Caddy گواهی را هر چند وقت تمدید می‌کند؛ اگر تمدید پشت پروکسی خطا داد، در Cloudflare یک Origin Certificate بسازید و در `Caddyfile` با `tls /path/cert.pem /path/key.pem` استفاده کنید.
۶. کش: فایل‌های `/_next/static/*` و `/api/uploads/*` از خود برنامه هدر کش بلندمدت دارند و Cloudflare آن‌ها را کش می‌کند. صفحه‌ها و `/api/v1/*` را کش نکنید (قیمت و موجودی باید زنده باشند).
۷. وب‌هوک اینستاگرام و بازگشت درگاه از همان دامنه کار می‌کنند؛ اگر WAF یا Bot Fight Mode فعال است، مسیرهای `/api/v1/webhooks/*` و `/api/v1/pay/*` را از چالش معاف کنید.
